# BUKHARA CINEMA — notes for Claude

- Owner communicates in Uzbek (Cyrillic). Replies and user-facing docs: Uzbek Cyrillic.
- Stack: C++17, Qt 6 Widgets; video engine MLT + FFmpeg (LGPL-only builds, no x264/x265, no GPL MLT modules).
- Windows builds run only in GitHub Actions (MSYS2 UCRT64 + BtbN LGPL FFmpeg shared build + windeployqt + Inno Setup). Never use MSYS2's ffmpeg/mlt packages in the shipped app: they are GPL builds. A `v*` tag publishes a GitHub Release. Locally test on Linux with `QT_QPA_PLATFORM=offscreen`.
- Never present a non-working feature as working: unfinished menu actions use `MainWindow::addPlanned()` (disabled, phase tag). Keep `FeatureStatus.cpp` and `docs/STATUS.md` in sync.
- Every UI string goes through `tr()`; add translations in `tools/translations.py`, then run `update_translations` target and `python3 tools/translations.py`. Test `translations_complete` must pass.
- Never commit media files. Never delete existing working code without reason.
- Architecture: `src/core` (Project model, MediaProbe; no widgets) ← `src/app` (ProjectController owns all project mutations; widgets only call it).
- `tests/bc_screenshot <dir> [media...]` renders the main window per language for visual checks.
- Video engine: `src/engine` (MLT). Windows CI builds MLT 7.42 from source with LGPL parts only (core, avformat, sdl2) and ships it as `lib/mlt` + `share/mlt`; Linux CI uses Ubuntu's MLT for tests only. `BC_MLT_PREFIX` points tests at another MLT install. Own MLT services in `src/engine/EngineServices.cpp`: producer `bc_still` (photos and titles with alpha, rendered by Qt) and filter `bc_gain` (clip volume, fades); video tracks are composited onto track 0 with core `composite`.
- Reliability (phase 5): `app/Autosave` writes copies to AppLocalData/autosave with a per-process `QLockFile`; copies without a live lock are offered by `RecoveryDialog` at start-up (`MainWindow::checkRecovery`, skipped in `--smoke-test`). `core/Backups` keeps old project files in `<project dir>/Backups` on save. `core/Waveform` peaks (200/s) are cached in CacheLocation/waveforms. Tests redirect autosave with `Autosave::setDirectory`.
- Proxies (phase 5b): `core/Proxy` makes 540p MPEG-4 Part 2 in Matroska with audio stream-copied (keeps start times equal for MLT). Stored via `core/MediaCache` (keyed by path+size+mtime). `TimelinePlayer::setProxies` swaps only the picture source; the Exporter never sets proxies. `core/Collector` copies a project + media into one folder.
- Source monitor (phase 6a): `app/ProjectSource.cpp` (part of ProjectController) plays a one-clip project in a second `TimelinePlayer`; In/Out points are per media id in memory only; `Timeline::place(item, v, a, start, in, length)` + `insertSpace` do insert/overwrite. Markers live in `Timeline::markers` (project format 4). Backwards playback (J) renders frames on a worker thread (`TimelinePlayer::startReverse`): MLT's sdl2_audio consumer jumps when started in reverse.
- Trim tools (phase 6b): `Timeline::roll/slip/slide/link/unlink` (core), `app/ProjectEditing.cpp` (controller: tools, link toggle, in-memory clip clipboard). `TimelineView::Tool` (Select V, Razor C, Roll N, Slip Y, Slide U) picks what a drag does; the actions live in `TimelinePanel` (shortcuts active while the timeline has focus).
- Nested sequences + shortcuts (phase 6c): `Project::nested` (`NestedSequence`, project format 5), `TimelineClip::nestId`. Undo snapshots `ProjectController::EditState` (main + nested + open id); use `editProject` for multi-timeline changes, `timeline()` is the open sequence. Engine: `TimelinePlayer::nestProducer` (cached, depth ≤ 8); export always uses the main sequence. `app/Shortcuts` stores user keys in QSettings `shortcuts/<objectName>` for named non-planned `act*` actions; `ShortcutsDialog` edits them.
- Motion (phase 7a): `core/Motion` (`ClipTransform` x/y as fraction of the frame, scale %, rotation °, opacity %; `ClipMotion` base or linear keys in *source* frames, so splits keep keys) on `TimelineClip::motion` (project format 6). Engine filter `bc_transform` (EngineServices, drawn with QPainter; `source_aspect` leaves letterbox bars out). Controller: `setClipTransform/setClipAnimated/toggleClipKey/resetClipMotion` (ProjectEditing.cpp); UI: Motion group in `ClipInspector`, key diamonds in `TimelineView`.
- Speed (phase 7b): `TimelineClip::speed` (0.1–10, media clips only); `src()/framesBefore()/framesAvailable()` convert timeline↔source frames and every cut/trim/slip/slide/roll uses them. Engine: MLT core `timewarp` producer (`producerFor(item, audio, speed)`, cut in = in/speed; `bc_transform` gets `speed` for keys); `Engine::init` sets `LC_NUMERIC=C` so MLT parses "1.5". Controller `setClipSpeed(id, speed, length, ripple)`; `SpeedDialog` (actSpeed, Ctrl+R) in `TimelinePanel`.
- Transitions (phase 8a): `TimelineClip::head/tail` (`ClipTransition`, project format 7). A cut transition lives on the later clip's `head`; `tail` only counts at a free end (`Timeline::transitionAt/setTransition`). Engine (`buildTractor` fill): cut transitions extend the cuts by handle frames and use `Mlt::Playlist::mix` + own `bc_xfade` (video) or core `mix` (audio); clips taking part are wrapped in a one-clip playlist so their filters survive the mix. Free ends: own `bc_fade` filter (video) or `bc_gain` fades (`lead` = handle frames). Ctrl+D = `addDefaultTransitions`.
- Effects (phase 8b): `core/Effects` (`ClipEffect` kind + params with specs, `applyEffects` pixel work on straight RGBA, `content` rect for letterbox) on `TimelineClip::effects` (video clips, project format 8). Engine filter `bc_effects` (JSON of active effects) is attached before `bc_transform`. Controller: `add/remove/moveClipEffect`, `setClipEffectEnabled/Value` (ProjectEditing.cpp); UI: `app/EffectsPanel` (right "Effects" tab). Phase 8c added kinds `ChromaKey` (hue distance → alpha, grey protection, spill to luma) and `Mask` (rect/ellipse, feather, invert; also hides letterbox bars) in the same pipeline.
- Colour (phase 9a): `core/Color` (`ClipColor` named values with specs, `applyColor` = per-channel LUT for white balance/exposure/contrast/tones + per-pixel saturation/vibrance) on `TimelineClip::color` (project format 9); `bc_effects` gets a `color` property applied before the effects. Controller `setClipColorValue/resetClipColor`; UI `app/ColorPanel` (right "Colour" tab). Phase 9b: `core/Lut` (.cube 3D/1D reader, trilinear, `Lut::cached` by path+mtime) via `ClipColor::lut` + `lut_amount`, applied after the basic correction; `Collector` copies LUT files to Media/. Phase 9c: `core/Scopes` (stats + `render` of waveform/parade/vectorscope/histogram into a QImage) shown by `app/ScopesPanel` in the hidden-by-default `scopesDock` (Window > Scopes, `actScopes`), fed by `programFrameReady`, drawn only while visible (80 ms throttle). Phase 9d: colour wheels as `ClipColor` values `lift|gamma|gain` + `_x/_y/_l` (`ClipColor::wheels/isWheelKey`, `wheelBalance` = luma-neutral RGB of a wheel point), applied in the per-channel table after the tones, before saturation; UI `app/ColorWheel` in ColorPanel; controller `setClipColorWheel` (x+y one undo step) / `resetClipColorWheels`.
- Audio mixer (phase 10a): `TimelineTrack::gainDb/pan` (audio tracks) and `Timeline::masterGainDb` (project format 10). Engine: per audio track playlist `bc_gain` (gain_db + pan) then own `bc_meter` (peaks stored under key `<player prefix><track id>`), master `bc_gain` + `bc_meter` attached to the tractor (meters only at depth 0); `TimelinePlayer::meterLevel`. Controller `setTrackGain/setTrackPan/setMasterGain` (merge per track), `meterLevel`; UI `app/AudioMixer` (right "Audio" tab, `LevelMeter`, objectNames `mixerFader_A1`/`mixerGain_master` etc.).
- Sound effects (phase 10b): `ClipEffect::Kind::Equalizer/Compressor` (`ClipEffect::isAudio`, `kinds(audio)`) in `TimelineClip::effects` of audio clips (project format 11; loading keeps only kinds that fit the track). DSP in `core/AudioFx` (`AudioChain`: RBJ biquads, linked soft-knee compressor, state across blocks). Engine filter `bc_audiofx` (JSON `effects`, resets on a position jump) before `bc_gain`. Controller effect functions accept any unlocked clip; `addClipEffect` checks kind vs track. `EffectsPanel` picks picture or sound (switch `effectTargetVideo/Audio` for linked pairs).
- Noise (phase 10c): kinds `NoiseReduction` (`core/AudioFx` `Denoiser`: STFT 1024/hop 256, sqrt-Hann, noise = average of the first 12 hops then tracked, spectral subtraction with floor; latency `Denoiser::kLatency` samples, `AudioChain::latency`) and `HumRemoval` (RBJ notches at f·h). Same `bc_audiofx` filter; no format change.
- Loudness (phase 10d): `core/Loudness` (BS.1770 `Meter` → `Profile` of 100 ms K-weighted powers + sample peaks; `blocks/integrate/measure` with -70/-10 gates; `compute` decodes with FFmpeg; cached as `MediaCache::Kind::Loudness` `.bcld` in the waveform folder). Controller `app/ProjectLoudness.cpp`: `analyzeLoudness` (background, `loudnessAnalyzed`), `clipLoudness/clipsLoudness` (source range in/src(length), before clip gain), `loudnessGains/normalizeLoudness` (sets `gainDb`, one undo step). UI `LoudnessDialog` via `actNormalizeLoudness` (TimelinePanel, Clip menu).
- Subtitles (phase 11a): `core/Subtitles` (`Subtitle` in frames, `SubtitleStyle`, `Srt::decode/parse/write`, cp1251 fallback) on `Timeline::subtitles/subtitleStyle` (project format 12; moved by `insertSpace`, `rescale`). Engine filter `bc_subtitles` on the tractor (JSON cues, drawn by `renderSubtitle` in TitleRenderer). `ExportSettings::burnSubtitles/writeSrt`. Controller `app/ProjectSubtitles.cpp`; UI `app/SubtitlesPanel` (right "Subtitles" tab, actions `actAddSubtitle/actImportSrt/actExportSrt` in the Graphics menu).
- Subtitle strip (phase 11b): `TimelineView` draws a `kSubsH` strip between ruler and tracks when there are subtitles (`tracksTop()`); drags `SubMove/SubTrim` call `setSubtitleTiming(..., merge=false)` on release; `subtitleClicked` → MainWindow opens the Subtitles tab, `SubtitlesPanel::currentChanged` → `setSelectedSubtitle`.
- Multicam (phase 12a): `core/AudioSync` (`envelope` = 10 ms RMS via FFmpeg, `match` = FFT cross-correlation of dB level minus 1 s mean, normalised per overlap; `align`). `NestedSequence::multicam` + `TimelineClip::angle` (project format 13): angle n = n-th video/audio track of the nest; `TimelinePlayer::nestProducer(..., angle)` builds only that track (cache key per angle). Controller `app/ProjectMulticam.cpp` (`createMulticam/isMulticam/multicamAngles/setClipAngle`); UI `MulticamDialog` from `MediaBinPanel::multicamAction` (Sequence menu), angle combos `clipVideoAngle/clipAudioAngle` in ClipInspector.
- Multicam monitor (phase 12b): `core/Multicam` (`columns/cell/angleAt` grid, `gridProject` = the nest with each video track placed in its cell via `ClipMotion::base`, no audio). Controller (ProjectMulticam.cpp): `multicamClipAt(frame, kind)`, `switchMulticamAngle(angle, kind)` (splitAt with linked clip at the playhead, part after gets the angle; one undo step), `requestMulticamGrid` (own `m_gridPlayer` built on the GUI thread, render on `m_gridPool`, newest wins) → `multicamGridReady`. UI `app/MulticamMonitor` in hidden `multicamDock` (`actMulticamMonitor`), actions `actMulticamCamera1..9` (keys 1-9) and `actMulticamSound1..9` (Alt+1-9) in Sequence submenus.
- Export queue (phase 13a): `app/ExportQueue` (jobs keep a *copy* of the Project + ExportSettings; one after another through `ProjectController::startExport(project, settings, err)`, which refuses while another export runs; same path waiting/running refused; failure → next job). UI `app/ExportQueueDialog` (non-modal, `actExportQueue` in File menu), `ExportDialog` button `exportAddQueue` (only when given a queue; the dialog ignores progress it did not start). `MainWindow::closeEvent` asks while the queue has work.
- Render preview (phase 13b): `core/RenderPreview` (`regions` = open sequence cut at video clip edges, never inside a transition; key = hash of the clips relative to the region + media path/size/mtime + nests + sequence + preview size; `heavy` = effects/colour/motion/speed/transitions/nested/2+ layers; `Writer` MPEG-4 intra 601 tv-range in Matroska, `Reader` exact inverse; files in `MediaCache::Kind::Preview`). Engine: own producer `bc_preview` (RGBA via Reader, loaded as `bc_preview:<path>`); `TimelinePlayer::setPreviews` puts the files on track 0 (no second composite: MLT's composite skews colours once) and cuts the video track playlists around them. Controller `app/ProjectPreview.cpp`: `previewParts`, `renderPreview(from,to)` (own player, worker thread, subtitles off), `cancelPreviewRender`, `deletePreviews`; `syncPlayer` → `applyPreviews`. UI: red/green bar in `TimelineView::drawRuler`, `actRenderPreview` (Enter on the timeline), `actDeletePreviews`, CacheDialog row `clearPreviews`.
- Mix loudness (phase 13c): `TimelinePlayer::renderAudio(from,to,sink)` (sequential get_frame, stereo f32 at the sequence rate). Controller `app/ProjectMixLoudness.cpp`: `measureMixLoudness` (own player of the open sequence without video clips, worker thread, `Loudness::Meter`), `mixLoudness(&current)` (current = same `m_graphRev`), `mixGain` (`Loudness::gainToTarget`, master range, 0.1 dB), `normalizeMix` (master volume, own undo step; shifts the stored result). UI `app/MixLoudnessDialog` (`actMixLoudness`, Sequence menu; shares QSettings loudness/target, loudness/ceiling).
- GPU (phase 13d): `core/HwAccel` (QSettings `gpu/decode` = auto|off|<type>; `available()` = candidates whose FFmpeg hw device opens; `applyToEngine` sets `MLT_AVFORMAT_HWACCEL`, called in `Engine::init` and by SettingsDialog; MLT 7.42's avformat producer falls back to software itself). `Proxy::make` decodes with `HwAccel::attach/download` and redoes the file on the CPU if that fails. Effects stay on the CPU. Export already used hardware encoders (phase 4).
- Scenes (phase 14a): `core/SceneDetect` (frames shrunk to 64x36 RGB, `difference` = histogram + pixel change, `cuts(profile, sensitivity, minGap)` = score above a floor and above k× the median of ±6 neighbours; profile cached as `MediaCache::Kind::Scenes` `.bcsc`; decodes via HwAccel). Controller `app/ProjectScenes.cpp`: queue on `m_scenePool` (one at a time), `sceneClips/analyzeScenes/scenesKnown/sceneCuts/splitAtScenes/markScenes` (source µs → sequence frames → timeline; splits from the last cut back). UI `app/SceneDialog` (`actDetectScenes`, Clip menu + timeline context menu). No AI model, offline.
- Interchange (phase 15a): `core/Interchange` (`write(project, Format, checkFiles)` → `Result{data, losses, clips, flattened, missingMedia}`): the main sequence is flattened first (nested clips → their inner clips cut to the shown part, multicam → only `angle`'s track; output tracks keep stacking: everything from main track n above track n-1), cut transitions resolved with the engine's handle rules (centred), then written as FCP7 xmeml v5 (clipitem start/end `-1` next to a transitionitem, in/out include the handles; Audio Levels filter for clip gain), OTIO JSON (hand-written so numbers are floats; Clip.1/Gap.1/Transition.1/Marker.2) or CMX 3600 EDL (V1 only, cuts). Speed is never carried (100 % from the same first frame); everything not carried is a `Loss` count shown by `app/InterchangeDialog` (`actExportInterchange`, File menu). Controller `app/ProjectInterchange.cpp`. Linux CI reads the files with the OpenTimelineIO reference library (`tests/check_interchange.py`) and checks `i18n/*.ts` against lupdate (`tools/check_ts_sync.py`).
- Interchange import (phase 15b): `core/InterchangeRead.cpp` (`Interchange::read(data, Format, seq, baseDir)` → `ReadResult{clips (ImportClip: path/name, kind, track, start/in/length in sequence frames, gainDb, head/tail, link), markers, losses (ImportLoss), fpsNum/Den, error}`): FCP7 via a small XML tree (shallowest `<sequence>` with `<media>`, files by id, `-1` start/end resolved from the neighbouring transitionitem, Audio Levels → gain, second mono channel of a stereo file dropped, links by union of `linkclipref`), OTIO (Clip.1/Clip.2, Gap, Transition → head dissolve; picture+sound of the same placement linked), CMX 3600 (record hour offset removed, drop frame, `D` pairs → dissolve centred on a cut, `AA/V`/`B` → linked pair, BL = black). Times converted to the sequence rate. Controller `readInterchange/interchangeMediaCount/importInterchange` (ProjectInterchange.cpp): media resolved by path, next to the file, or by name in the bin; new files in a bin folder named after the timeline, missing ones as offline items; one undo step that adds a `NestedSequence` + nested clip at the playhead, or the clips straight onto the open sequence. UI `app/InterchangeImportDialog` (`actImportInterchange`, File menu). Linux CI imports files written by the OpenTimelineIO library (`tests/make_interchange_refs.py`).
- VST 3 plug-ins (phase 15c-1): Steinberg VST 3 SDK 3.8.1 (MIT) fetched by `cmake/Vst3Sdk.cmake` (only base/pluginterfaces/public.sdk sources; static `bc_vst3host`; option `BC_ENABLE_VST3`). `core/Vst3Host` (plain C++, `bc::vst3`: `standardBundles/findBundles/describeBundle` (moduleinfo.json first, else load), `moduleInfoJson`, `Plugin` = component + controller, normalized params, `prepare/process/reset`). `ClipEffect::Kind::Plugin` ("vst3", `pluginPath/pluginId/pluginName`, params `p<id>` 0..1; project format 14) runs as an `AudioChain` stage (instance reused per path|id; a missing plug-in is skipped, sound passes). `app/Vst3Plugins` (GUI thread: scan cached in QSettings `vst3/cache`, extra folders `vst3/folders` + env `BC_VST3_PATH`, crash guard `vst3/scanning` → `vst3/bad`, `uiInstance` for names/value texts). Controller `addClipPlugin` (ProjectEditing.cpp); EffectsPanel lists plug-ins as "VST 3: name", sliders `effectParam_p<id>` (+`_text`), button `effectFindPlugins`. Trademark: VST Compatible logo in the About box (`:/vst/vst-compatible.png`), README, and "VST is a registered trademark of Steinberg Media Technologies GmbH." Tests use `tests/vst3/BcTestGain.cpp` (`bc_add_test_vst3`).
- Plug-in host (phase 15c-2): `BukharaPluginHost` (src/pluginhost/main.cpp, static, installed next to the app) runs one plug-in per process; `core/Vst3Ipc` (two streams: requests answered by the same type / posts, and events Edited/EditorClosed; Win32 named pipes with overlapped I/O + job object, POSIX socketpair + posix_spawn; `[type][size][payload]`), `core/Vst3Remote` (`RemotePlugin`, only changed values sent, timeouts `setTimeouts` 3 s process / 30 s load → hung = killed). `vst3::Plugin` is abstract: `create` = remote when `setHostProgram` is set (main.cpp: `Vst3Plugins::useHostProgram(appDir)`), `createLocal` in-process. A crash/hang is remembered (`crashMessage`/`forgetCrash`, `noteFailure` 10 s back-off for starts that fail); `AudioChain` drops a crashed instance and does not restart it until forgotten. Scan uses `describeBundleIsolated`. Editors (Windows only): `LocalPlugin::openEditor` (own top-level Win32 window, `IPlugFrame`, `IComponentHandler` → edit callback; helper marshals every request to its window thread), app `Vst3Plugins::openEditor` sessions (one remote instance per open window, edits → `setClipEffectValue`, `timelineChanged` → values back / window closed when the effect is gone). EffectsPanel: `effectPluginWindow`, `effectPluginCrashed` + `effectPluginRestart`, 1 s crash watch. Test plug-in hidden params Crash (2) and Hang (3); its window (Windows) sets Gain 0.75 on attach. Tests `tst_phase15c2`.
- Auto multicam (phase 16a): `core/AutoMulticam` (`plan(levels, picture, fps, from, to, Settings)` → `Plan{cuts, share, separation}`; Speaker: per camera 0.4 s smoothed dB minus its 5th-percentile unsmoothed background, speech ≥ 8 dB, leader by `margin`, 0.5 s hold, cut 0.15 s early but never before the picture, `minShot`, `maxShot` → wide/next best; no opinion keeps the shot; Rhythm: mt19937 `seed`, no repeat; envelopes cached as `MediaCache::Kind::Envelope` `.bcen`). Controller `app/ProjectAutoMulticam.cpp` (`autoMulticamClips/multicamSoundKnown/analyzeMulticamSound` on `m_soundPool` → `multicamSoundProgress/Ready`, `autoMulticamPlan` (camera n = n-th audio/video track of the nest, clip in/speed mapped), `applyAutoMulticam` = splitAt from the last cut back + angles, one undo step; linked sound split, keeps its angle). UI `app/AutoMulticamDialog` (`actAutoMulticam`, Sequence menu; QSettings `autoMulticam/*`). Tests `tst_phase16a`.
