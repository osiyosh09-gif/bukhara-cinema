# BUKHARA CINEMA

Windows учун мустақил профессионал видеомуҳаррир.
Интерфейс тиллари: ўзбекча (кирилл ва лотин) ва русча.

> **Ҳозирги ҳолат: 6-босқичнинг 1-қисми (версия 0.9.0): Source монитор, In/Out нуқталари, insert/overwrite, J/K/L, маркерлар.**
> Лойиҳа → импорт → timeline’да монтаж → матн ва овоз → сақлаш → MP4 экспорт
> занжири ишлайди. Кейинги босқичлардаги функциялар менюда кулранг
> (ўчирилган) ва қайси босқичда келиши ёзилган. Тўлиқ рўйхат:
> [docs/STATUS.md](docs/STATUS.md).

### Timeline’да ишлаш

- Медиани кутубхонадан timeline’га судраб ташланг. Видео V йўлакка, унинг овози A йўлакка тушади ва улар боғланган бўлади.
- Клипни сичқонча билан кўчиринг (бошқа йўлакка ҳам). Клип четидан тортиб қисқартиринг ёки узайтиринг.
- Юқоридаги вақт чизғичини босиб курсорни қўйинг; **Ctrl+K** курсор жойида бўлади.
- **Delete** — ўчириш, **Shift+Delete** — бўшлиқни ёпиб ўчириш, **Ctrl+Z / Ctrl+Shift+Z** — бекор қилиш / қайтариш.
- **S** — ёпишишни (snapping) ёқиш/ўчириш, **Ctrl + ғилдирак** — масштаб, **\\** — бутун секвенцияни кўрсатиш, **← →** — бир кадр.
- Йўлак номи ёнидаги қулф уни таҳрирдан ҳимоялайди, кўз белгиси уни Натижа мониторидан яширади.
- **Пробел** (Space) — ижро ёки тўхтатиш. Натижа монитори остидаги тугмалар: бошига, бир кадр орқага, ижро, бир кадр олдинга, охирига.
- Секин компьютерда овоз узилмаслиги учун баъзи кадрлар ташлаб кетилади (тасвир бир оз сакраши мумкин, овоз эса текис эшитилади).

### Source монитор, In/Out ва маркерлар

- Медиа кутубхонасида клипни **икки марта босинг** (ёки ўнг тугма → **Source мониторида очиш**): у чапдаги **Source** мониторида очилади. Монитор остидаги чизиқни босиб ёки суриб керакли жойга ўтинг.
- **I** — ишлатиладиган қисмнинг боши (In), **O** — охири (Out). Белгиланган қисм чизиқда кўк рангда кўринади. **Ctrl+Shift+X** — белгиларни олиб ташлаш.
- **, (вергул)** — Insert: қисм timeline'даги курсор жойига қўйилади, кейинги клиплар ўнгга сурилади. **. (нуқта)** — Overwrite: қисм курсор жойидагининг устидан ёзилади. Иккаласи ҳам биринчи қулфланмаган V ва A йўлакка тушади ва **Ctrl+Z** билан бекор бўлади.
- Кутубхонадан судраб ташлаганда ҳам белгиланган In/Out қисми тушади.
- **J / K / L** — орқага ўйнатиш / тўхташ / олдинга ўйнатиш. J ёки L ни яна боссангиз тезлик 2, 4, 8 баравар ошади. Орқага ижрода овоз йўқ. Охирги босилган монитор (номи сариқ) J/K/L ва Пробелни қабул қилади.
- **M** — курсор жойига маркер (яшил байроқча), **Shift+M** — кейинги маркерга, **Ctrl+Shift+M** — олдингисига. **Маркерлар** менюсида номлаш ва ўчириш. Маркерлар лойиҳада сақланади.
- In/Out нуқталари ҳозирча дастур ёпилгунча эслаб қолинади (лойиҳа файлига ёзилмайди).

### Матн ва овоз

- **Графика → Янги матн** (**Ctrl+T**) курсор турган жойга 5 сонияли титр қўяди (бўш энг юқори V йўлакка). Матнни ўнгдаги **Клип** панелида ёзинг: ўлчами, ранги, жойи (юқорида / ўртада / пастда) ва матн орқасидаги қора фон ҳам шу ерда.
- Титрни бошқа клиплар каби кўчириш, қисқартириш, бўлиш мумкин. Шаффоф PNG расмлар ҳам пастки йўлакни кўрсатиб туради.
- Аудио клипни танланг (**G** ёки **Клип → Овоз кучайтириш...**): **Клип** панелида овоз баландлиги (dB) ва fade in / fade out (сонияда).
- Аудио йўлак номи ёнида **M** — йўлак овозини ўчиради, **S** (Solo) — фақат шу йўлакни эшитиш.

### MP4 экспорт

- **Файл → Экспорт...** (**Ctrl+M**) ёки юқоридаги **Экспорт** тугмаси. Файл номи, сифатни (юқори / ўрта / кичик файл) танланг ва **Экспорт**ни босинг.
- Видео H.264 бўлади: компьютерда Intel Quick Sync (Intel видеокартаси), Windows Media Foundation, NVIDIA ёки AMD кодловчиси қидирилади. Ҳеч бири ишламаса MPEG-4 Part 2 ишлатилади ва ойнада бу ҳақда огоҳлантириш чиқади. Овоз — AAC.
- Ўлчам ва кадр тезлиги секвенция созламаларидан олинади (Секвенция → Секвенция созламалари).
- Жараён кўрсаткичи ва қолган вақт кўринади; **Экспортни бекор қилиш** тугаланмаган файлни ўчиради.

### Ишни йўқотмаслик

- **Автосақлаш:** сақланмаган ўзгаришлар бўлса, дастур ҳар 2 дақиқада лойиҳа нусхасини алоҳида папкага ёзади (сизнинг `.bcproj` файлингизга тегмайди). Оралиқни **Файл → Созламалар**да ўзгартириш ёки ўчириш мумкин.
- **Тиклаш:** дастур кутилмаганда ёпилса (ток ўчса, осилиб қолса), кейинги очилишда «Сақланмаган ишни тиклаш» ойнаси чиқади. **Тиклаш**ни босинг ва кейин **Ctrl+S** билан сақланг.
- **Олдинги версиялар:** ҳар сақлашда эски файл лойиҳа ёнидаги `Backups` папкасида қолади (охирги 20 таси, созламада ўзгаради). **Файл → Олдинги версиялар...** ойнасида керакли вақтни танланг; у фақат сиз сақлаганингизда асосий лойиҳанинг ўрнига ўтади.
- **Овоз тўлқини:** аудио клипларда овоз тўлқини кўринади; у фонда бир марта ҳисобланади ва кэшда сақланади.

### Катта видеолар (proxy) ва лойиҳани йиғиш

- **Proxy:** 4K каби Full HD'дан катта видео импорт қилинганда дастур фонда унинг енгил нусхасини (540p) тайёрлайди; пастда «Proxy тайёрланяпти: 37%» кўринади. Шундан кейин бундай видео секин компьютерда ҳам равон ижро бўлади. Бошқа видео учун: медиа кутубхонасида ўнг тугма → **Proxy тайёрлаш**.
- **Секвенция → Ижрода proxy ишлатиш** уларни ёқади/ўчиради. **Экспорт ҳар доим асл файллардан** қилинади, сифат йўқолмайди.
- **Файл → Медиа кэши...** thumbnail, овоз тўлқини ва proxy файллар қанча жой олганини кўрсатади ва уларни ўчиради (керак бўлса қайта тайёрланади).
- **Файл → Лойиҳани йиғиш...** лойиҳа файли ва ишлатилган медиани битта янги папкага (`<ном>/Media/...`) нусхалайди: бошқа компьютерга ўтказиш ёки архивлаш учун.

## Дастурни ўрнатиш (оддий фойдаланувчи учун)

Энг осон йўл: репозиторийнинг **Releases** бўлимидан охирги версиянинг
`BukharaCinema-Setup-….exe` файлини юклаб олинг ва ишга туширинг.

Синов йиғмалари (Releases’да ҳали йўқ версиялар):

1. GitHub’да шу репозиторийнинг **Actions** бўлимини очинг.
2. Энг охирги муваффақиятли (яшил белгили) **build** ишини танланг.
3. Пастдаги **Artifacts** бўлимидан `BukharaCinema-…-windows` ни юклаб олинг.
4. Юклаб олинган ZIP’ни очинг. Ичида иккита файл бор:
   - `BukharaCinema-Setup-….exe` — ўрнатувчи. Икки марта босинг ва кўрсатмаларга амал қилинг.
     Администратор ҳуқуқи шарт эмас.
   - `BukharaCinema-portable-….zip` — ўрнатмасдан ишлатиш учун: очинг ва `BukharaCinema.exe` ни ишга туширинг.
5. Windows SmartScreen «Неизвестный издатель» деса: **Подробнее → Выполнить в любом случае**.
   Бу дастур ҳали рақамли имзоланмагани учун чиқади.

Талаблар: Windows 10 (1809 ёки янгироқ) ёки Windows 11, 64-bit. Интернет керак эмас.

## Тилни алмаштириш

**Файл → Созламалар… → Интерфейс тили**. Тил дарҳол ўзгаради ва эсда сақланади.

## Технологиялар

- C++17, Qt 6 (Widgets) — интерфейс
- FFmpeg (LGPL йиғмаси) — медиа файлларни ўқиш, thumbnail (1-босқичдан)
- MLT 7.42 (LGPL) — timeline ижроси ва кейинчалик экспорт двигатели. Windows учун манбадан фақат LGPL қисмлари (core, avformat, sdl2) йиғилади
- SDL 2 (zlib) — овоз чиқариш
- Inno Setup — Windows ўрнатувчиси
- GitHub Actions — Windows’да автомат йиғиш, тест ва ўрнатувчи

Лицензиялар: [licenses/THIRD_PARTY.md](licenses/THIRD_PARTY.md).

## Дастурчилар учун

```bash
# Linux (Ubuntu 24.04)
sudo apt install qt6-base-dev qt6-tools-dev qt6-l10n-tools qt6-tools-dev-tools ninja-build \
  libavformat-dev libavcodec-dev libavutil-dev libswscale-dev ffmpeg pkg-config
cmake -S . -B build -G Ninja
cmake --build build
ctest --test-dir build --output-on-failure
./build/BukharaCinema
```

Windows’да MSYS2 UCRT64 муҳити ва BtbN’нинг FFmpeg LGPL йиғмаси
(`-DFFMPEG_ROOT=…`) ишлатилади; аниқ қадамлар
[.github/workflows/build.yml](.github/workflows/build.yml) да.

### Таржималар

Код ичидаги матнлар инглизча (`tr("...")`). Таржималар `tools/translations.py`
файлида ёзилади (ўзбекча кирилл ва русча; лотин ёзуви кириллдан автоматик
ўгирилади).

```bash
cmake --build build --target update_translations   # янги матнларни .ts га қўшади
python3 tools/translations.py                       # таржималарни тўлдиради
```

`translations_complete` тести таржимаси йўқ матн қолса хато беради.
