Windows учун мустақил профессионал видеомуҳаррир.
Интерфейс тиллари: ўзбекча (кирилл ва лотин) ва русча.

### Timeline’да ишлаш

- Медиани кутубхонадан timeline’га судраб ташланг. Видео V йўлакка, унинг овози A йўлакка тушади ва улар боғланган бўлади.
- Клипни сичқонча билан кўчиринг (бошқа йўлакка ҳам). Клип четидан тортиб қисқартиринг ёки узайтиринг.
- Юқоридаги вақт чизғичини босиб курсорни қўйинг; **Ctrl+K** курсор жойида бўлади.
- **Delete** — ўчириш, **Shift+Delete** — бўшлиқни ёпиб ўчириш, **Ctrl+Z / Ctrl+Shift+Z** — бекор қилиш / қайтариш.
- **S** — ёпишишни (snapping) ёқиш/ўчириш, **Ctrl + ғилдирак** — масштаб, **\\** — бутун секвенцияни кўрсатиш, **← →** — бир кадр.
- Йўлак номи ёнидаги қулф уни таҳрирдан ҳимоялайди, кўз белгиси уни Натижа мониторидан яширади.
- **Пробел** (Space) — ижро ёки тўхтатиш. Натижа монитори остидаги тугмалар: бошига, бир кадр орқага, ижро, бир кадр олдинга, охирига.
- Секин компьютерда овоз узилмаслиги учун баъзи кадрлар ташлаб кетилади (тасвир бир оз сакраши мумкин, овоз эса текис эшитилади).

### Source монитор, In/Out ва маркерлар

- Медиа кутубхонасида клипни **икки марта босинг** (ёки ўнг тугма → **Source мониторида очиш**): у чапдаги **Source** мониторида очилади. Монитор остидаги чизиқни босиб ёки суриб керакли жойга ўтинг.
- **I** — ишлатиладиган қисмнинг боши (In), **O** — охири (Out). Белгиланган қисм чизиқда кўк рангда кўринади. **Ctrl+Shift+X** — белгиларни олиб ташлаш.
- **, (вергул)** — Insert: қисм timeline'даги курсор жойига қўйилади, кейинги клиплар ўнгга сурилади. **. (нуқта)** — Overwrite: қисм курсор жойидагининг устидан ёзилади. Иккаласи ҳам биринчи қулфланмаган V ва A йўлакка тушади ва **Ctrl+Z** билан бекор бўлади.
- Кутубхонадан судраб ташлаганда ҳам белгиланган In/Out қисми тушади.
- **J / K / L** — орқага ўйнатиш / тўхташ / олдинга ўйнатиш. J ёки L ни яна боссангиз тезлик 2, 4, 8 баравар ошади. Орқага ижрода овоз йўқ. Охирги босилган монитор (номи сариқ) J/K/L ва Пробелни қабул қилади.
- **M** — курсор жойига маркер (яшил байроқча), **Shift+M** — кейинги маркерга, **Ctrl+Shift+M** — олдингисига. **Маркерлар** менюсида номлаш ва ўчириш. Маркерлар лойиҳада сақланади.
- In/Out нуқталари ҳозирча дастур ёпилгунча эслаб қолинади (лойиҳа файлига ёзилмайди).

### Монтаж асбоблари, нусхалаш ва боғлаш

Timeline устида асбоб тугмалари бор (timeline'ни босиб, ҳарф билан ҳам танланади):

- **V — Танлаш:** оддий режим: танлаш, кўчириш, четидан қисқартириш.
- **C — Пичоқ (Razor):** клипни босган жойингизда иккига бўлади (овози билан).
- **N — Roll:** икки клип орасидаги кесимни суради: бири узаяди, иккинчиси қисқаради, секвенция узунлиги ўзгармайди.
- **Y — Slip:** клип жойи ва узунлиги қолади, ичида манбанинг бошқа қисми кўринади.
- **U — Slide:** клипни қўшниларининг орасида суради; олдинги клип охири ва кейинги клип боши мос ўзгаради.
- **Ctrl+C / Ctrl+X / Ctrl+V:** танланган клипларни нусхалаш / кесиш / курсор жойига қўйиш. **Ctrl+Shift+V** — қўйиб, кейинги клипларни ўнгга суради.
- **Ctrl+L:** танланган видео ва овозни боғлаш ёки ажратиш (ажратилгандан кейин уларни алоҳида кўчириш мумкин).
- Ҳамма амал **Ctrl+Z** билан бекор бўлади.

### Клипни суриш, катталаштириш, буриш (Motion) ва keyframe'лар

- Timeline'да видео клип ёки титрни танланг. «Клип» панелида **Ҳаракат** бўлими чиқади: Жой X/Y (пикселда), Ўлчам (%), Бурилиш (°), Шаффофлик (%).
- Қийматни ўзгартирсангиз, клип бутун узунлиги бўйича шундай бўлади.
- **Анимация** белгисини ёқсангиз, keyframe'лар ишлайди: playhead'ни керакли жойга қўйиб, қийматни ўзгартирасиз ва у ерга keyframe тушади. Икки keyframe орасида қиймат равон ўзгаради (масалан, аста-секин катталашиш ёки пайдо бўлиш).
- ◆ тугмаси playhead жойига keyframe қўяди ёки олиб ташлайди, ◀ ва ▶ олдинги ва кейинги keyframe'га ўтади. Клип пастида keyframe'лар олтин ромбча бўлиб кўринади.
- **Тиклаш** ҳаммасини олиб ташлайди. Ҳамма амал Ctrl+Z билан бекор бўлади, клипни бўлсангиз keyframe'лар жойида қолади.
- Ҳозирча: расмни мониторда сичқонча билан суриб бўлмайди (қиймат панелда ёзилади), keyframe'лар орасида фақат текис (linear) ўтиш бор, тезлик учун пастга қаранг.

### Тезликни ўзгартириш

- Клипни танлаб, **Клип > Тезлик / давомийлик...** (ёки **Ctrl+R**, ёки клипдаги ўнг тугма менюси).
- Тезликни фоизда ёзинг (10% дан 1000% гача) ёки керакли давомийликни сонияда ёзинг: бири ўзгарса, иккинчиси ўзи ҳисобланади.
- 200% да клип икки баравар тез ва икки баравар қисқа бўлади, 50% да секин ва узун. Timeline'да клип номи ёнида [200%] кўринади.
- **Кейинги клипларни суриш** белгиланса, клип узайганда ёки қисқарганда ундан кейинги клиплар ҳам сурилади. Белгиланмаса, узайган клип кейинги клипгача боради.
- Боғланган овоз ҳам бирга тезлашади, шунда овоз тони ҳам ўзгаради (тезда ингичка, секинда йўғон).
- Ҳозирча: орқага ижро (reverse), аста-секин тезлик ўзгариши (speed ramp) ва тонни сақлаш йўқ; расм ва титр клипларига ҳамда ички секвенцияга тезлик берилмайди.

### Ўтишлар (transitions)

- Клипни танлаб, playhead'ни кесим ёнига қўйинг ва **Ctrl+D** босинг (ёки **Клип > Ўтиш қўшиш**): энг яқин кесимга 1 сониялик cross dissolve тушади. Боғланган овозга ҳам crossfade қўйилади.
- «Клип» панелидаги **Ўтишлар** бўлимида клип боши ва охири учун тур ва узунлик танланади: Cross dissolve, Қорага ўтиш, Оққа ўтиш, Чапдан ёки Ўнгдан сидириш. Овоз клипи учун: Crossfade.
- Икки клип ёнма-ён турса, ўтиш уларни аралаштиради; кесим ўртада бўлади. Бунинг учун файлда клипдан ташқари ортиқча кадр керак; йўқ бўлса, ўтиш кесимдан бир томонга силжийди ёки қисқаради.
- Клипнинг бўш учида (ёнида клип йўқ) клип аста пайдо бўлади ёки йўқолади.
- Timeline'да ўтиш оқ тўртбурчак ва чизиқ билан кўринади. Ҳамма ўзгариш Ctrl+Z билан бекор бўлади.
- Ҳозирча: ўтишни timeline'да сичқонча билан чўзиб бўлмайди (узунлик панелда ёзилади), ўтишлар рўйхати «Эффектлар» панелида эмас.

### Клип эффектлари

- Timeline'да видео, расм ёки титр клипини танланг ва ўнгдаги **Эффектлар** панелини очинг.
- Рўйхатдан эффектни танлаб **Қўшиш**ни босинг: Ёрқинлик ва контраст, Тўйинганлик (0% = оқ-қора), Хиралаштириш, Ўткирлаш, Кесиш (чап, ўнг, юқори, паст, % да), Ойна (чап-ўнг ёки тепа-паст алмашади).
- Эффект олдидаги белгини олсангиз, у вақтинча ўчади: солиштириш учун қулай. ▲ ▼ тугмалари тартибни ўзгартиради; эффектлар юқоридан пастга навбат билан ишлайди.
- Эффектлар расмга ҳаракат (жой, ўлчам, бурилиш) созламаларидан олдин қўйилади. Эффектли клип timeline'да «fx» белгиси билан кўринади. Ҳамма ўзгариш Ctrl+Z билан бекор бўлади, клип бўлинганда иккала қисмда ҳам эффектлар қолади.
- Ҳамма эффект ўзимизнинг коддан ишлайди: пулли хизмат ёки GPL модули йўқ, интернет керак эмас.
- Ҳозирча: эффект қийматлари вақт бўйича ўзгармайди (keyframe йўқ), катта хиралаштириш тўлиқ HD'да ижрони секинлаштириши мумкин.

### Chroma key ва маскалар

- **Chroma key (рангни олиб ташлаш):** яшил ёки кўк фонда олинган клипни юқоридаги йўлакка (масалан V2) қўйинг, остига (V1) фон клипини қўйинг. «Эффектлар» панелида Chroma key қўшинг: яшил ранг шаффоф бўлади ва остидаги клип кўринади.
  - **Ранг (hue), °**: 120 = яшил, 240 = кўк. **Чегара** ва **Юмшоқлик** қанча яқин рангларни олиб ташлашни белгилайди. **Кулранг ҳимояси** оқ, қора ва кулранг жойларга тегмайди. **Spill тозалаш** одам четидаги яшил аксни камайтиради.
- **Маска:** тўртбурчак ёки эллипс шаклидаги қисм қолади, қолгани шаффоф бўлади. Марказ ва ўлчам расмга нисбатан %да, **Юмшоқ чет** пикселда. **Тескари** белгиланса, шакл ичи яширилади.
- Иккаласи ҳам бошқа эффектлар каби рўйхатда туради, тартибини ўзгартириш ва ўчириб қўйиш мумкин.
- Ҳозирча: рангни мониторда томизғич билан олиб бўлмайди (рақам билан ёзилади), маскани мониторда сичқонча билан чизиб ёки суриб бўлмайди, эркин шаклли (bezier) ва вақт бўйича ҳаракатланадиган маскалар йўқ.

### Ранг тузатиш

- Timeline'да видео, расм ёки титр клипини танланг ва ўнгдаги **Ранг** панелини очинг. Ҳар бир қиймат учун слайдер ва рақам майдони бор.
- **Оқ баланс:** Ҳарорат (чапга совуқроқ, кўкроқ; ўнгга иссиқроқ, сариқроқ), Тус (чапга яшилроқ, ўнгга пушти).
- **Ёруғлик:** Экспозиция (+1 = икки баравар ёруғ), Контраст, Ёруғ жойлар, Қоронғи жойлар (қора ва оқ жойида қолади).
- **Ранг:** Тўйинганлик (0% = оқ-қора), Vibrance (хира рангларни кучлироқ, ёрқинларини камроқ ўзгартиради).
- **Ранг ғилдираклари:** учта ғилдирак: **Lift** (қоронғи жойлар), **Gamma** (ўрта тонлар), **Gain** (ёруғ жойлар). Ғилдиракдаги нуқтани рангга томон суринг: масалан, Lift'ни кўкка, Gain'ни сариққа суриш соя жойларни совуқ, ёруғ жойларни иссиқ қилади. Ўртадан қанча узоқ бўлса, ранг шунча кучли. Ғилдирак остидаги слайдер шу тонларни қоронғироқ ёки ёруғроқ қилади. Нуқтани икки марта босиш уни ўртага қайтаради; стрелка тугмалари 1 тадан (Shift билан 10 тадан) суради. **Ғилдиракларни тиклаш** учаласини қайтаради.
- Ранг тузатиш эффектлардан олдин қўйилади. **Рангни асл ҳолига** тугмаси ҳаммасини қайтаради; слайдерни суриш битта Ctrl+Z қадами.
- **Кўриниш (LUT):** «.cube файлни танлаш...» тугмаси билан тайёр LUT файлини (Premiere, DaVinci Resolve ва бошқа дастурлар ишлатадиган 3D ёки 1D .cube) қўйинг; **Кучи, %** уни аслига аралаштиради. LUT асосий ранг тузатишдан кейин қўйилади. «Олиб ташлаш» уни клипдан олади.
- LUT файли лойиҳага кўчирилмайди, фақат йўли сақланади. **Лойиҳани йиғиш** LUT файлларини ҳам Media папкасига нусхалайди. Файл топилмаса, расм ўзгармайди ва панелда номи қизил ёзилади.
- **Scope'лар:** «Ойна > Scope'лар» ойнасини очинг. Улар Program мониторидаги кадрни кўрсатади:
  - **Waveform** — ҳар бир устуннинг ёруғлиги (0 = қора, 100 = оқ). 100 дан юқорига ёки 0 дан пастга урилган жойлар «куйган» бўлади.
  - **RGB parade** — қизил, яшил, кўк алоҳида; оқ баланс тўғри бўлса, кулранг жойларда учаласи бир хил баландликда.
  - **Vectorscope** — ранг тури (бурчак) ва тўйинганлик (марказдан узоқлик). Квадратлар соф ранглар, штрих чизиқ одам териси ранги.
  - **Гистограмма** — ҳар бир ёруғлик даражасида қанча пиксел борлиги.
  - Scope'лар фақат ойна очиқ турганда ҳисобланади, шунинг учун кучсиз компьютерни ортиқча юкламайди.
- Ҳозирча: қийматлар вақт бўйича ўзгармайди, ранг ғилдираклари кейинги қисмда.

### Ички секвенция (nested sequence) ва тезкор тугмалар

- Бир неча клипни танлаб, **Клип > Nest** ни танланг (клипдаги ўнг тугма менюсида ҳам бор). Улар битта бирюза рангли клипга айланади; уни бутун бир клип каби кўчириш, қисқартириш ва бўлиш мумкин.
- Ички секвенцияни **икки марта босинг**: у timeline'да очилади ва ичидаги клипларни одатдагидек таҳрирлайсиз. Ўзгариш ташқаридаги клипда дарров кўринади.
- Timeline устидаги рўйхатдан **Асосий секвенция**га қайтасиз; «Номини ўзгартириш...» тугмаси очиқ ички секвенция номини ўзгартиради.
- Экспорт ҳар доим асосий секвенциядан қилинади.
- **Таҳрир > Тезкор тугмалар...**: буйруқни танланг, янги тугмани босинг. Тугма бошқа буйруқда бўлса, у ердан олиб ташланади ва бу ёзиб кўрсатилади. «Асл ҳолати» ва «Ҳаммасини асл ҳолига» тугмалари бор; танловингиз компьютерда сақланади.
- Ҳозирча: ишлатилмаган ички секвенцияни ўчириш тугмаси йўқ (лойиҳада қолади), Slip асбоби ички секвенция клипида ишламайди, ички секвенция клипини охиридан узайтирсангиз қора кадр кўринади.

### Матн ва овоз

- **Графика → Янги матн** (**Ctrl+T**) курсор турган жойга 5 сонияли титр қўяди (бўш энг юқори V йўлакка). Матнни ўнгдаги **Клип** панелида ёзинг: ўлчами, ранги, жойи (юқорида / ўртада / пастда) ва матн орқасидаги қора фон ҳам шу ерда.
- Титрни бошқа клиплар каби кўчириш, қисқартириш, бўлиш мумкин. Шаффоф PNG расмлар ҳам пастки йўлакни кўрсатиб туради.
- Аудио клипни танланг (**G** ёки **Клип → Овоз кучайтириш...**): **Клип** панелида овоз баландлиги (dB) ва fade in / fade out (сонияда).
- Аудио йўлак номи ёнида **M** — йўлак овозини ўчиради, **S** (Solo) — фақат шу йўлакни эшитиш.

### MP4 экспорт

- **Файл → Экспорт...** (**Ctrl+M**) ёки юқоридаги **Экспорт** тугмаси. Файл номи, сифатни (юқори / ўрта / кичик файл) танланг ва **Экспорт**ни босинг.
- Видео H.264 бўлади: компьютерда Intel Quick Sync (Intel видеокартаси), Windows Media Foundation, NVIDIA ёки AMD кодловчиси қидирилади. Ҳеч бири ишламаса MPEG-4 Part 2 ишлатилади ва ойнада бу ҳақда огоҳлантириш чиқади. Овоз — AAC.
- Ўлчам ва кадр тезлиги секвенция созламаларидан олинади (Секвенция → Секвенция созламалари).
- Жараён кўрсаткичи ва қолган вақт кўринади; **Экспортни бекор қилиш** тугаланмаган файлни ўчиради.

### Ишни йўқотмаслик

- **Автосақлаш:** сақланмаган ўзгаришлар бўлса, дастур ҳар 2 дақиқада лойиҳа нусхасини алоҳида папкага ёзади (сизнинг `.bcproj` файлингизга тегмайди). Оралиқни **Файл → Созламалар**да ўзгартириш ёки ўчириш мумкин.
- **Тиклаш:** дастур кутилмаганда ёпилса (ток ўчса, осилиб қолса), кейинги очилишда «Сақланмаган ишни тиклаш» ойнаси чиқади. **Тиклаш**ни босинг ва кейин **Ctrl+S** билан сақланг.
- **Олдинги версиялар:** ҳар сақлашда эски файл лойиҳа ёнидаги `Backups` папкасида қолади (охирги 20 таси, созламада ўзгаради). **Файл → Олдинги версиялар...** ойнасида керакли вақтни танланг; у фақат сиз сақлаганингизда асосий лойиҳанинг ўрнига ўтади.
- **Овоз тўлқини:** аудио клипларда овоз тўлқини кўринади; у фонда бир марта ҳисобланади ва кэшда сақланади.

### Катта видеолар (proxy) ва лойиҳани йиғиш

- **Proxy:** 4K каби Full HD'дан катта видео импорт қилинганда дастур фонда унинг енгил нусхасини (540p) тайёрлайди; пастда «Proxy тайёрланяпти: 37%» кўринади. Шундан кейин бундай видео секин компьютерда ҳам равон ижро бўлади. Бошқа видео учун: медиа кутубхонасида ўнг тугма → **Proxy тайёрлаш**.
- **Секвенция → Ижрода proxy ишлатиш** уларни ёқади/ўчиради. **Экспорт ҳар доим асл файллардан** қилинади, сифат йўқолмайди.
- **Файл → Медиа кэши...** thumbnail, овоз тўлқини ва proxy файллар қанча жой олганини кўрсатади ва уларни ўчиради (керак бўлса қайта тайёрланади).
- **Файл → Лойиҳани йиғиш...** лойиҳа файли ва ишлатилган медиани битта янги папкага (`<ном>/Media/...`) нусхалайди: бошқа компьютерга ўтказиш ёки архивлаш учун.

## Дастурни ўрнатиш (оддий фойдаланувчи учун)

Энг осон йўл: репозиторийнинг **Releases** бўлимидан охирги версиянинг
`BukharaCinema-Setup-….exe` файлини юклаб олинг ва ишга туширинг.

Синов йиғмалари (Releases’да ҳали йўқ версиялар):

1. GitHub’да шу репозиторийнинг **Actions** бўлимини очинг.
2. Энг охирги муваффақиятли (яшил белгили) **build** ишини танланг.
3. Пастдаги **Artifacts** бўлимидан `BukharaCinema-…-windows` ни юклаб олинг.
4. Юклаб олинган ZIP’ни очинг. Ичида иккита файл бор:
   - `BukharaCinema-Setup-….exe` — ўрнатувчи. Икки марта босинг ва кўрсатмаларга амал қилинг.
     Администратор ҳуқуқи шарт эмас.
   - `BukharaCinema-portable-….zip` — ўрнатмасдан ишлатиш учун: очинг ва `BukharaCinema.exe` ни ишга туширинг.
5. Windows SmartScreen «Неизвестный издатель» деса: **Подробнее → Выполнить в любом случае**.
   Бу дастур ҳали рақамли имзоланмагани учун чиқади.

Талаблар: Windows 10 (1809 ёки янгироқ) ёки Windows 11, 64-bit. Интернет керак эмас.

## Технологиялар

- C++17, Qt 6 (Widgets) — интерфейс
- FFmpeg (LGPL йиғмаси) — медиа файлларни ўқиш, thumbnail (1-босқичдан)
- MLT 7.42 (LGPL) — timeline ижроси ва кейинчалик экспорт двигатели. Windows учун манбадан фақат LGPL қисмлари (core, avformat, sdl2) йиғилади
- SDL 2 (zlib) — овоз чиқариш
- Inno Setup — Windows ўрнатувчиси
- GitHub Actions — Windows’да автомат йиғиш, тест ва ўрнатувчи

Лицензиялар: [licenses/THIRD_PARTY.md](licenses/THIRD_PARTY.md).

## Дастурчилар учун

```bash
# Linux (Ubuntu 24.04)
sudo apt install qt6-base-dev qt6-tools-dev qt6-l10n-tools qt6-tools-dev-tools ninja-build \
  libavformat-dev libavcodec-dev libavutil-dev libswscale-dev ffmpeg pkg-config
cmake -S . -B build -G Ninja
cmake --build build
ctest --test-dir build --output-on-failure
./build/BukharaCinema
```

Windows’да MSYS2 UCRT64 муҳити ва BtbN’нинг FFmpeg LGPL йиғмаси
(`-DFFMPEG_ROOT=…`) ишлатилади; аниқ қадамлар
[.github/workflows/build.yml](.github/workflows/build.yml) да.

### Таржималар

Код ичидаги матнлар инглизча (`tr("...")`). Таржималар `tools/translations.py`
файлида ёзилади (ўзбекча кирилл ва русча; лотин ёзуви кириллдан автоматик
ўгирилади).

```bash
cmake --build build --target update_translations   # янги матнларни .ts га қўшади
python3 tools/translations.py                       # таржималарни тўлдиради
```

`translations_complete` тести таржимаси йўқ матн қолса хато беради.
